Different Rolled Homogeneous Armour (RHA) thicknesses for small caliber weapons used in the game Arma3 designed for tests with [arma3diag_x64.exe](https://community.bistudio.com/wiki/Arma_3:_Diagnostics_Exe) (Arma3 Dev branch) and `"Shots" diag_enable true;` or `"Shots" diag_enable false;` (Editor missions for each thickness included).
